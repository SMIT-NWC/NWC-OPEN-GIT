# NWC_PUBLIC — Public Source Usage Guide

## 1. Usage and Modification

The NWC public source may be freely used and modified by individuals and organizations without prior approval, provided that the terms of this License are followed.

### Permitted Uses Without Prior Approval
- Viewing and downloading publicly available source code
- Personal learning, research, and technical evaluation
- Running and testing NWC in development and test environments
- Modifying, extending, and improving the source code
- Building and operating internal corporate business systems
- Applying NWC to customer projects and delivering project results
- Developing and operating websites, applications, and commercial services
- Integrating NWC into commercial products and services

Note: Use for actual business and commercial purposes is permitted. Ordinary use and modification do not require prior approval or a separate license application.

## 2. Restrictions on Use

The following activities are prohibited:

- Selling the original NWC source code or modified versions as independent products, libraries, or development tools
- Independently publishing or distributing the original NWC source code or modified versions through separate repositories, websites, or file-sharing services
- Reselling or providing the original NWC source code or modified versions as independent software
- Removing or modifying existing copyright notices, source attribution, or license notices without authorization
- Claiming sole ownership of the copyright of the original NWC source code or modified versions

### Delivery of Project Deliverables

The use and operation of business systems, websites, and applications developed using NWC are permitted.

Project deliverables containing NWC configuration files may also be provided to customers or operators to the extent necessary for project development, operation, and maintenance.

However, all copyright and license notices must be retained. Providing such deliverables does not grant the recipient independent rights to resell or redistribute NWC itself.

## 3. GitHub Fork and Repository Usage

- Viewing, cloning, downloading, and forking the NWC_PUBLIC repository within GitHub are permitted.
- Copies created through GitHub Fork remain subject to this License.
- Creating a GitHub Fork does not grant independent redistribution or resale rights outside GitHub.

## 4. Public Source Management Principles

Only source code approved for public release from NWC_DEV may be published in the NWC public repository.

The following items must be reviewed before publication:

- Inclusion of confidential information or authentication credentials
- Compliance with third-party copyright and license requirements
- External libraries and dependency information
- Appropriateness of publishing source maps and build artifacts
- README links and related documentation references
