## ✨ NWC 소개

**NWC**는 웹 화면 개발에 필요한 UI 컴포넌트와 개발 패턴을 제공하여 프로젝트 전반에서 일관된 사용자 경험과 유지보수하기 쉬운 화면 구성을 돕는 웹 컴포넌트 기반 프레임워크입니다.

본 저장소는 SMIT에서 공개하는 NWC 소스 코드와 개발 문서, 샘플을 제공하는 **Public 저장소**입니다. 공개된 자료는 개인 개발자와 기업 등 누구나 확인하고 활용할 수 있습니다.

## 📋 이용 안내

NWC 공개 소스는 개인 및 기업 모두 자유롭게 활용할 수 있습니다. 별도의 사전 승인이나 이용 신청 없이 다운로드, 사용 및 수정이 가능합니다.

| 구분 | 이용 조건 | 주요 내용 |
|---|---|---|
| 소스 열람 및 다운로드 | 허용 | 누구나 자유롭게 이용 |
| Clone 및 GitHub 내 Fork | 허용 | GitHub 서비스 내 Fork 가능 |
| 소스 수정 및 기능 추가 | 허용 | 개인 및 기업 모두 가능 |
| 개인 학습, 연구 및 테스트 | 허용 | 자유롭게 활용 가능 |
| 기업 내부 시스템 적용 | 허용 | 업무 시스템 개발 및 운영 |
| 상업적 프로젝트 활용 | 허용 | 고객사 프로젝트 및 서비스 개발 |
| 프로젝트 산출물 제공 | 허용 | 프로젝트 구축·운영·유지보수에 필요한 범위에서 제공 가능 |
| 원본·수정본 자체 재판매 | 금지 | 독립적인 상품으로 판매하거나 유료 제공 불가 |
| 독립적인 무단 재배포 | 금지 | 별도 저장소·웹사이트·소프트웨어 형태의 배포 제한 |
| 저작권 표시 삭제 및 변경 | 금지 | 기존 저작권, 출처 및 라이선스 고지 유지 필요 |

**꼭 확인해 주세요.**

- NWC를 활용한 상업적 서비스 개발과 운영은 허용됩니다.
- NWC 원본 소스 또는 수정본 자체를 독립적인 상품으로 판매하거나 무단 재배포하는 것은 금지됩니다.
- GitHub Fork는 허용되지만, GitHub 외부에서의 독립적인 재판매 또는 재배포 권한을 의미하지 않습니다.
- 프로젝트의 구축·운영·유지보수에 필요한 범위에서 고객사 또는 운영 주체에게 NWC 구성 파일을 포함한 프로젝트 산출물을 제공할 수 있습니다. 이 경우 저작권 및 라이선스 고지를 유지해야 하며, 전달받은 자에게 NWC 자체의 독립적인 재판매 또는 재배포 권한이 부여되는 것은 아닙니다.
- NWC에 포함된 제3자 라이브러리, 폰트, 이미지 및 패키지는 각 권리자의 라이선스를 별도로 따릅니다.

**공개된 NWC 소스의 일반적인 다운로드, 사용 및 수정은 별도의 승인이나 문의 대상이 아닙니다.**

상세한 권리와 의무는 [LICENSE](./LICENSE)를 확인해 주세요.

## 🚀 주요 기능

| 영역 | 설명 |
|---|---|
| **UI Components** | 입력, 버튼, 그리드 등 화면 개발에 활용하는 UI 컴포넌트 |
| **Layout & Navigation** | 레이아웃, 탭, MDI, 메뉴 등 화면 구성과 이동을 지원하는 컴포넌트 |

| **Sample** | 컴포넌트 사용법과 업무 화면 구현 패턴을 확인할 수 있는 예제 |
| **Docs** | 컴포넌트별 사용법, 속성, 이벤트 및 개발 참고 자료 |
| **FAQ** | 개발 과정에서 자주 확인하는 질문과 문제 해결 정보 |

## ⚡ 시작하기

NWC를 처음 사용하는 경우 저장소의 공개 소스를 내려받고, 프로젝트 환경에서 샘플을 실행해 보는 것부터 시작할 수 있습니다.

### 1. 저장소 내려받기

Git을 사용하는 경우 다음 명령으로 저장소를 Clone합니다.

```bash
git clone https://github.com/SMIT-NWC/NWC-OPEN-GIT.git
```

Git을 사용하지 않는 경우 GitHub 저장소 화면에서 **Code → Download ZIP**을 선택해 내려받을 수 있습니다.

### 2. 프로젝트 및 실행 환경 확인

내려받은 저장소에서 문서와 샘플을 확인하고, 실행하려는 예제의 안내에 따라 프로젝트 환경을 준비합니다.

- 샘플별 필요한 파일과 의존성 확인
- 프로젝트의 NWC 로딩 및 초기화 설정 확인
- 사용하는 브라우저와 실행 환경 확인
- 샘플에 안내된 실행 방법에 따라 화면 실행

> NWC는 프로젝트의 구성 및 실행 환경에 따라 필요한 설정과 의존성이 달라질 수 있습니다. 별도의 패키지 설치 명령이나 실행 명령을 임의로 적용하지 말고, 각 샘플과 문서에 안내된 방법을 확인해 주세요.

### 3. 기본 컴포넌트 확인

NWC 화면에서는 프로젝트에 NWC가 정상적으로 로딩된 환경에서 웹 컴포넌트를 사용할 수 있습니다.

```html
<nc-input label="검색어"></nc-input>
<nc-button>조회</nc-button>
```

위 코드는 컴포넌트의 기본 사용 형태를 보여주는 간단한 예시입니다. 독립 실행을 위해서는 NWC 로딩, 컴포넌트 등록 및 프로젝트별 초기화 설정이 필요합니다.

### 4. 다음 단계

저장소의 문서와 샘플을 통해 컴포넌트별 사용법과 실제 화면 구현 방식을 확인해 보세요.

## 🧩 주요 컴포넌트

NWC는 화면 구성과 업무 기능 구현에 활용할 수 있는 다양한 컴포넌트를 제공합니다.

| 구분 | 컴포넌트 예시 | 주요 용도 |
|---|---|---|
| 입력 및 동작 | `nc-input`, `nc-textarea`, `nc-checkbox`, `nc-radio`, `nc-select`, `nc-button` | 데이터 입력, 선택 및 사용자 동작 |
| 데이터 표시 | `nc-grid` | 목록 및 데이터 표시 |
| 화면 구성 | `nc-layout`, `nc-panel`, `nc-card`, `nc-accordion` | 화면 영역 및 콘텐츠 구성 |
| 내비게이션 | `nc-tab`, `nc-mdi`, `nc-menu`, `nc-treeview` | 탭, 다중 화면, 메뉴 및 트리 구조 |
| 피드백 및 오버레이 | `nc-dialog`, `nc-tooltip`, `nc-progress`, `nc-gauge` | 안내, 대화상자 및 상태 표시 |

위 목록은 주요 컴포넌트의 예시이며 전체 목록은 아닙니다. 각 컴포넌트의 상세 속성, 이벤트 및 사용 방법은 공개된 개발 문서를 확인해 주세요.

## 🛠️ 개발 및 개선 제안

공개 소스의 오류를 발견했거나 개선 의견이 있는 경우 GitHub 저장소의 Issues 기능이 활성화되어 있다면 이를 통해 제보할 수 있습니다.
